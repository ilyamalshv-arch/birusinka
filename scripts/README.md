# scripts — дев-тулинг (НЕ часть сайта)

Эти скрипты **не входят в приложение**: их никто не импортирует, они не участвуют
в сборке (`next build`) и не попадают в прод. Это разовый инструментарий, которым
ассеты и размеры вытаскивались из Figma, а результат сверялся с макетом.

Запускать из корня репозитория: `node scripts/<файл>.mjs`.
Скриптам, обращающимся к Figma, нужен personal access token (read-only) в переменной
окружения (в репозиторий он не коммитится — лежит в env / `.env.local` под `.gitignore`):

```bash
# PowerShell
$env:FIGMA_TOKEN="figd_..."; node scripts/figma-pull.mjs file
```

## Файлы

| Скрипт | Что делает |
|---|---|
| `figma-pull.mjs` | Тянет точные данные из Figma по REST API: дерево нод, размеры, цвета, шрифты. Команды: `file`, `kids <id>`, `node <id> [depth]`, `img <id> [svg\|png]`. Результат — в `./figma/` (сырой JSON + читаемый спек). |
| `export-assets.mjs` | Выгружает ассеты главной в `public/assets/`: растры (лого, фото, баннеры) через image-fills и иконки в SVG. `node scripts/export-assets.mjs svg` — только иконки. |
| `optimize-assets.mjs` | Сжимает выгруженные картинки через `sharp` (некоторые филлы приходят из Figma гигантскими). |
| `compare.mjs` | QA: накладывает собранную страницу на PNG-экспорт макета и режет посекционные сравнения (header / hero / cards / promo / footer) — ловить пиксельные расхождения. |
| `compare-mobile.mjs` | То же для мобильной ширины. |
| `compare-detail.mjs` | Прицельные кропы в нативном 2× (карточка, иконки, лого) для детальной сверки. |

## Зачем это в репозитории

Чтобы пиксель-перфект был воспроизводим: страница версталась по реальным числам из
Figma, а не «на глаз», и сверялась с макетом автоматическим диффом. Выводы скриптов
(папка `figma/`) репозиторием игнорируются — они регенерируются.
